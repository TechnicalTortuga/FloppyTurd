## Notes
- All rendering commands are routed through delegates and the proxy system for platform abstraction.
- MetalRenderer handles pipeline state, draw calls, and texture registration.
- AssetManager loads assets, caches them, and interacts with delegates for platform-specific logic.
- The asset catalog must contain an image set named `poophat` for correct loading.
- Metal shaders are defined in `.metal` files and compiled into `.metallib`.
